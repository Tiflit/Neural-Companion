# Current source candidates and licence evidence

Reviewed 2026-10-19. Evidence is bound to the revisions below. This is documentation/licence triage, not a security audit, performance result, exhaustive transitive audit or incorporation approval. Public descriptions were evaluated as claims, not demonstrated capabilities. No component was installed or executed in this review.

A permissive source licence does not clear all dependencies, weights, proprietary DLLs or release archives. Copyleft is open source; specific copying/linking/adaptation/distribution still needs a compatible plan. Noncommercial/no-derivatives restrictions are not ordinary open-source permissions. Missing grants block implementation reuse under the present evidence. No implementation, binary, model or game content is incorporated by these notes.

This supplements [the historical licence register](../LICENSE-REVIEW.md), follows [source review rules](../SOURCE-REVIEW.md), and supports the curated [research priorities](../RESEARCH.md). A source's appearance here is not an allowlist. Exact files, copyright/NOTICE duties and the intended use must be recorded before implementation transfer. Framework support, provider support and model rights remain separate.

## Deferred leads and ambiguity

Linux presentation/pacing leads (afmf-linux, Radiant, MAKO and historical lsfg-vk forks) are not initial Windows implementation candidates. Offline video tools (Video2X, REAL-Video-Enhancer and REFEREE) do not validate an interactive game pipeline. Installer variants, presets and UI prototypes add no demonstrated input or inference capability; evaluate them only for a specific gap.

“Prism” did not identify a unique project: Skynizz/Prism, NodeNestor/prism-inference and NodeNestor/prism-optiscaler are distinct. No Prism dependency is selected. Unnamed forks and similarly named bridges remain unreviewed identities.
